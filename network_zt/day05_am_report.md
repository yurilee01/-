## 4교시 · 구역 규칙 코드

### 문제 4-1 · 규칙 판정 코드 읽고 설명하기

- (가) 함수 `default_policy` · `match_rule` · `judge` 가 각각 무엇을 하는지 적어 주세요.
  - 쓸 내용: 「default_policy: … / match_rule: … / judge: …」 함수마다 자유롭게
  - 답:
  default_policy는 일치하는 규칙이 없을 때 기본적으로 허용할지 차단할지 정합니다. match_rule은 요청이 규칙과 일치하는지 확인합니다. judge는 규칙을 위에서부터 확인하고 요청의 허용 또는 차단 여부를 판정합니다.
- (나) `judge` 가 리턴하는 값 두 개는 무엇이고, 어느 줄이 만드나요?
  - 쓸 내용: 「값 ①: … / 값 ②: … / 만드는 줄: …」
  - 답:
  동작(permit 또는 deny)과 규칙 번호입니다. return rule[4], rule[0]에서 규칙의 동작과 번호를 리턴하고, 일치하는 규칙이 없으면 return default_policy(src, dst), 0에서 기본 정책의 동작과 번호 0을 리턴합니다.
- (다) 🔍 `judge` 의 `for` 는 맞는 규칙을 찾으면 바로 `return` 합니다. 같은 요청에 규칙이 둘 이상 맞는다면 어느 규칙이 적용되나요? 왜 `return` 으로 바로 끝내도록 만들었나요?
  - 쓸 내용: ① 규칙이 둘 이상 맞을 때 적용되는 규칙 ② 방화벽이 「첫 번째로 맞는 규칙」을 쓴다는 점과 이어서 `return` 으로 바로 끝내는 이유
  - 답:
  규칙표에서 위쪽에 있는 첫 번째 규칙이 적용됩니다. return을 실행하면 함수가 바로 끝나기 때문에 뒤에 있는 규칙은 확인하지 않습니다. 따라서 먼저 일치하는 규칙으로 빠르게 판정할 수 있습니다.
